# 第二题：Book 类设计

## 题目

定义一个 Book 类：

- 私有成员：title（string）、price（float）、stock（int）；
- 公有成员函数：构造函数、析构函数、input()、display()。

在 main() 中：

- 用 new 动态创建一个 Book 对象；
- 通过指针调用 input() 输入数据；
- 通过指针调用 display() 输出数据；
- 用 delete 释放内存。

输入示例：

```text
C++入门
45.5
20
```

输出示例：

```text
书名：C++入门
价格：45.5
库存：20
```

## 我的思路

### 1. 为什么成员要放在 private

title、price、stock 是书的内部数据。把它们放在 private 里，外面就不能随便写 book->price = -100 这种不合理的值，只能通过类自己提供的函数来操作，这样更安全。

### 2. 构造函数和析构函数

- 构造函数的名字和类名一样，没有返回值，创建对象时自动执行。我在里面把三个成员初始化成空字符串、0 和 0。
- 析构函数的名字是 ~Book()，对象销毁时自动执行。这个类没有用 new 申请额外的资源，所以析构函数里暂时不需要写东西，但题目要求定义，我还是把它写出来了。

### 3. 为什么用 getline 读书名

cin >> title 遇到空格就会停下来，如果书名是 C++ Primer 中文版，就只能读到 C++。getline(cin, title) 会一直读到换行符，能把带空格的一整行读进来。

### 4. new 和 delete

```cpp
Book *book = new Book();  // 在堆上创建对象
book->input();            // 指针用 -> 访问成员
delete book;              // 释放内存，同时调用析构函数
```

new 创建的对象不会自己释放，必须手动 delete，否则程序运行久了会内存泄漏。delete 之后我把指针设成 nullptr，防止以后不小心再使用它。

## 为什么输入时没有提示语

题目给的输入输出示例里只有书名、价格、库存三行，没有“请输入书名”这样的提示。为了让程序输出和示例完全一致，我在 input() 里没有加 cout 提示语，直接读数据。

## 编译和运行

```bash
g++ -std=c++17 main.cpp -o main
./main
```

然后依次输入：

```text
C++入门
45.5
20
```

## 运行结果

```text
书名：C++入门
价格：45.5
库存：20
```

## 一点收获

以前我习惯直接写 Book book; 在栈上创建对象，这次用了 new，才真正分清楚“对象本身”和“指向对象的指针”。book->input() 里的 -> 就是“通过指针访问成员”的意思。

另外，析构函数不输出内容，是为了不让多余的文字混进题目要求的输出里。如果想观察它什么时候执行，可以临时在析构函数里加一句 cout，看完再删掉。
