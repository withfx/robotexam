# 第三题：统计英文字母、数字和其他字符

## 题目

输入一个字符串，统计其中英文字母、数字、其他字符的个数，并分别输出。

## 我的思路

1. 用 getline(cin, text) 读一整行。不能直接用 cin >> text，因为它一遇到空格就停了，后面的内容会读不到；
2. 用 for 循环从头到尾遍历字符串；
3. 用 cctype 头文件里的两个函数判断字符类型：
   - isalpha(ch)：是英文字母，letter_count 加 1；
   - isdigit(ch)：是数字 0~9，digit_count 加 1；
   - 两个都不是：空格、逗号、感叹号等，other_count 加 1；
4. 最后把三个计数器输出。

## 为什么用 unsigned char

isalpha 和 isdigit 原本是给字符编码用的，参数要求能表示 unsigned char 的范围。string 里的元素是 char，如果字符编码是负数，直接传进去可能出问题，所以我先转换了一下：

```cpp
unsigned char ch = static_cast<unsigned char>(text[i]);
```

## 编译和运行

```bash
g++ -std=c++17 main.cpp -o main
./main
```

输入：

```text
Hello, ROS2 2024!
```

## 运行结果

```text
英文字母个数：8
数字个数：5
其他字符个数：4
```

数一下：

- 字母：H e l l o R O S，共 8 个；
- 数字：2 2 0 2 4，共 5 个；
- 其他：逗号、逗号后面的空格、2 和 2024 中间的空格、感叹号，共 4 个。

## 一个需要注意的地方

这个程序是按“字节”遍历 string 的。英文字母和数字都只占一个字节，所以结果正确。

如果一个汉字按 UTF-8 保存，它会占 3 个字节，程序会把一个汉字算成 3 个“其他字符”。本题要求统计的是英文字母和数字，测试时用英文、数字和符号就可以了。如果以后要正确处理中文，需要按 UTF-8 的规则解码，那是更进一步的内容。

## 一点收获

这次分清了 cin >> 和 getline 的区别：前者读单词，后者读一整行。还知道了字符判断函数要包含 cctype 头文件，以及 char 可能是负数这个以前没注意过的细节。
