# 第一题：成绩从高到低排序

## 题目

输入 10 名同学的成绩：

```text
78、92、65、88、70、95、82、60、100、85
```

把这些成绩按从高到低（降序）排序后输出。

## 我的思路

题目已经把 10 个成绩给出来了，所以我直接把它们放进一个 int 数组，没有再从键盘读一遍。

排序用的是课上讲过的**冒泡排序**：

1. 从数组第一个元素开始，依次比较相邻的两个数；
2. 如果前面的数比后面的数小，就把它们交换；
3. 这样比较完一轮，最小的那个数就会被换到数组最后面；
4. 下一轮就不用再管最后面已经排好的数，所以内层循环的次数是 9 - i；
5. 10 个数一共执行 9 轮，整个数组就变成从大到小了。

## 代码里几个容易写错的地方

- 数组下标是从 0 开始的，最后一个元素是 scores[9]，所以循环条件写成 i < 10；
- 内层比较的是 scores[j] 和 scores[j + 1]，j 最大只能到 8，因此条件是 j < 9 - i；
- 交换两个变量需要一个临时变量 temp，不能直接写 a = b; b = a;，那样第一个值会丢；
- 输出时用 if (i > 0) 控制空格，避免最后一个数字后面多一个空格。

## 编译和运行

在 question1 目录下执行：

```bash
g++ -std=c++17 main.cpp -o main
./main
```

## 运行结果

```text
从高到低排序后的成绩：100 95 92 88 85 82 78 70 65 60
```

## 一点收获

冒泡排序的时间复杂度是 O(n²)，数据量大的时候会比较慢。10 个成绩很少，用冒泡完全没问题，而且能让我把“比较”和“交换”这两个动作弄清楚。

C++ 的 algorithm 头文件里还有一个 sort 函数，也可以配合 greater&lt;int&gt;() 实现降序，以后写大项目时用它会更方便。
